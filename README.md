# This project automatically loads 3D fighter jet models, places them in randomized HDRI environments, changes camera position, distance, angle, lighting, and object orientation, then renders images together with YOLO object detection labels and metadata.

# 

# \## Features

# 

# \* Automatic loading of multiple 3D models

# \* Automatic loading and cycling of HDRI environments

# \* Random camera position and viewing angle

# \* Random camera distance and focal length

# \* Random object rotation and pose

# \* Randomized HDRI rotation and lighting intensity

# \* Automatic YOLO bounding-box generation

# \* Automatic metadata generation

# \* Configurable number of:

# 

# &#x20; \* total images

# &#x20; \* images per object

# &#x20; \* images per environment

# \* Automatic switching between models and environments

# \* Support for multiple 3D formats including:

# 

# &#x20; \* GLB / GLTF

# &#x20; \* FBX

# &#x20; \* OBJ

# &#x20; \* STL

# &#x20; \* BLEND

# 

# \## Example

# 

# \### Images

# 

# Rendered synthetic RGB images generated by Blender.

# 

# \### YOLO Labels

# 

# Each image has a corresponding `.txt` file in YOLO object detection format:

# 

# ```text

# class\_id center\_x center\_y width height

# ```

# 

# All coordinates are normalized between `0` and `1`.

# 

# Example:

# 

# ```text

# 0 0.512341 0.463210 0.324510 0.217820

# ```

# 

# \### Metadata

# 

# Each generated image also has a JSON metadata file containing information such as:

# 

# \* model name

# \* HDRI environment

# \* camera distance

# \* camera focal length

# \* camera angle

# \* camera shift

# \* aircraft orientation

# \* lighting settings

# \* bounding box coordinates

# 

# \## Configuration

# 

# The main dataset settings are located near the top of:

# 

# ```text

# blender\_jet\_dataset\_generator.py

# ```

# 

# Example:

# 

# ```python

# MAX\_IMAGES\_PER\_ENV = 10

# IMAGES\_PER\_OBJECT = 5

# TOTAL\_IMAGES = 100

# ```

# 

# \### `MAX\_IMAGES\_PER\_ENV`

# 

# Maximum number of images generated before switching to another environment.

# 

# \### `IMAGES\_PER\_OBJECT`

# 

# Number of images generated for each 3D object before switching to another model.

# 

# \### `TOTAL\_IMAGES`

# 

# Total number of images that should be generated.

# 

# The generator automatically cycles through available models and environments until the requested total number of images is reached.

# 

# \## Camera Randomization

# 

# For every generated image, the camera can randomly change:

# 

# \* distance from the object

# \* azimuth

# \* elevation

# \* focal length

# \* horizontal framing

# \* vertical framing

# 

# This prevents the object from always appearing at the same distance, angle, or position in the image.

# 

# \## Running the Generator

# 

# \### 1. Open Blender

# 

# Launch Blender.

# 

# \### 2. Open the Scripting Workspace

# 

# Go to:

# 

# ```text

# Scripting

# ```

# 

# \### 3. Open the Script

# 

# Open:

# 

# ```text

# blender\_jet\_dataset\_generator.py

# ```

# 

# \### 4. Configure the Paths

# 

# Set your local paths for:

# 

# ```python

# MODEL\_FOLDER

# ENV\_FOLDER

# OUTPUT\_FOLDER

# ```

# 

# \### 5. Run

# 

# Click:

# 

# ```text

# Run Script

# ```

# 

# The generator will first validate the available models and environments.

# 

# Example:

# 

# ```text

# \[OK] MODEL: dassault\_rafale.glb

# \[OK] MODEL: eurofighter\_typhoon\_3d.glb

# 

# \[OK] ENV: hochsal\_forest\_4k.exr

# \[OK] ENV: portland\_landing\_pad\_4k.exr

# 

# READY: 3 valid object(s), 2 valid environment(s)

# ```

# 

# After validation, dataset generation starts automatically.

#

# \## Why Synthetic Data?

# 

# Collecting and manually labeling real-world computer vision datasets can be expensive and time-consuming.

# 

# Using Blender makes it possible to automatically generate large numbers of labeled images while controlling:

# 

# \* camera pose

# \* lighting

# \* object orientation

# \* backgrounds

# \* object scale

# \* dataset size

# 

# This makes synthetic data useful for prototyping and training computer vision systems.
