# تولیدکننده دیتاست مصنوعی با Blender

[English README](README.md)

این پروژه یک پایپ‌لاین خودکار برای تولید دیتاست‌های مصنوعی بینایی ماشین با استفاده از Blender و مدل‌های سه‌بعدی است.

هدف پروژه این است که بدون نیاز به جمع‌آوری و لیبل‌گذاری دستی تصاویر، بتوان از مدل‌های سه‌بعدی در محیط‌های مختلف، تصاویر متنوع تولید کرد و هم‌زمان برای هر تصویر، لیبل YOLO و اطلاعات متادیتا ساخت.

در نسخه فعلی پروژه از مدل‌های سه‌بعدی جت جنگنده برای نمایش عملکرد سیستم استفاده شده است، اما ساختار پروژه به‌گونه‌ای طراحی شده که بتوان آن را برای خودرو، پهپاد، ربات، قطعات صنعتی، محصولات و بسیاری از آبجکت‌های دیگر نیز استفاده کرد.

## تنظیمات اصلی

مهم‌ترین تنظیمات پروژه در ابتدای فایل زیر قرار دارند:

```text
blender_jet_dataset_generator.py
```

برای مثال:

```python
MAX_IMAGES_PER_ENV = 10
IMAGES_PER_OBJECT = 5
TOTAL_IMAGES = 100
```

### MAX_IMAGES_PER_ENV

حداکثر تعداد تصاویری که در یک محیط تولید می‌شوند.

بعد از رسیدن به این عدد، محیط تغییر می‌کند.

### IMAGES_PER_OBJECT

تعداد تصاویری که از هر مدل سه‌بعدی تولید می‌شود.

بعد از رسیدن به این عدد، مدل بعدی بارگذاری می‌شود.

### TOTAL_IMAGES

تعداد کل تصاویر موردنیاز برای دیتاست.

مدل‌ها و محیط‌ها به صورت چرخه‌ای دوباره استفاده می‌شوند تا تعداد کل تصاویر به مقدار تعیین‌شده برسد.

## رندوم‌سازی دوربین

برای جلوگیری از تولید تصاویر تکراری، در هر رندر پارامترهای مختلف دوربین تغییر می‌کنند.

از جمله:

- فاصله دوربین از سوژه
- زاویه افقی دوربین
- زاویه عمودی دوربین
- ارتفاع دوربین
- Focal Length
- موقعیت افقی سوژه در کادر
- موقعیت عمودی سوژه در کادر

این موضوع باعث می‌شود سوژه همیشه در مرکز تصویر، در یک اندازه ثابت یا از یک زاویه مشخص دیده نشود.

## رندوم‌سازی سوژه

مدل سه‌بعدی نیز می‌تواند در هر تصویر تغییر وضعیت داشته باشد.

پارامترهای قابل تغییر شامل:

- Yaw
- Pitch
- Roll

این تغییرات باعث افزایش تنوع دیتاست می‌شوند.

## محیط و نورپردازی

در نسخه فعلی پروژه از فایل‌های HDRI برای ایجاد پس‌زمینه و نور محیط استفاده می‌شود.

برای هر تصویر می‌توان موارد زیر را نیز تغییر داد:

- چرخش HDRI
- شدت نور HDRI
- نور Directional کمکی

به این ترتیب یک مدل می‌تواند در شرایط نوری و محیطی متفاوت رندر شود.

## خروجی دیتاست

خروجی پروژه به صورت کلی ساختاری مشابه زیر دارد:

```text
outputs/
├── images/
├── labels/
├── metadata/
└── classes.txt
```

### Images

تصاویر RGB رندرشده توسط Blender.

### Labels

برای هر تصویر یک فایل متنی با فرمت YOLO تولید می‌شود.

فرمت YOLO:

```text
class_id center_x center_y width height
```

تمام مختصات بین صفر و یک نرمال‌سازی می‌شوند.

نمونه:

```text
0 0.512341 0.463210 0.324510 0.217820
```

### Metadata

برای هر تصویر یک فایل JSON نیز می‌تواند ذخیره شود.

این فایل شامل اطلاعاتی مانند موارد زیر است:

- نام مدل
- نام محیط
- فاصله دوربین
- Focal Length
- زاویه دوربین
- Camera Shift
- زاویه مدل
- تنظیمات نور
- مختصات Bounding Box

## بررسی بصری لیبل‌ها

فایل زیر برای بررسی کیفیت لیبل‌های تولیدشده در پروژه قرار داده شده است:

```text
draw_labels.py
```

این اسکریپت تصاویر و فایل‌های YOLO را می‌خواند و Bounding Box را روی تصاویر رسم می‌کند.

به این ترتیب می‌توان بدون باز کردن تک‌تک فایل‌های لیبل، به صورت بصری بررسی کرد که Bounding Boxها درست تولید شده‌اند یا خیر.

## اجرای پروژه

### 1. اجرای Blender

Blender را باز کنید.

### 2. ورود به بخش Scripting

از Workspaceهای بالای Blender وارد بخش:

```text
Scripting
```

شوید.

### 3. باز کردن اسکریپت اصلی

فایل زیر را باز کنید:

```text
blender_jet_dataset_generator.py
```

### 4. تنظیم مسیرها

مسیر مدل‌ها، محیط‌ها و خروجی را مشخص کنید:

```python
MODEL_FOLDER
ENV_FOLDER
OUTPUT_FOLDER
```

### 5. تنظیم تعداد تصاویر

برای مثال:

```python
MAX_IMAGES_PER_ENV = 10
IMAGES_PER_OBJECT = 5
TOTAL_IMAGES = 100
```

### 6. اجرای اسکریپت

روی گزینه:

```text
Run Script
```

کلیک کنید.

قبل از شروع تولید دیتاست، برنامه ابتدا فایل‌های موجود را بررسی می‌کند.

نمونه خروجی:

```text
[OK] MODEL: dassault_rafale.glb
[OK] MODEL: eurofighter_typhoon_3d.glb

[OK] ENV: hochsal_forest_4k.exr
[OK] ENV: portland_landing_pad_4k.exr

READY: 3 valid object(s), 2 valid environment(s)
```

بعد از اعتبارسنجی فایل‌ها، تولید دیتاست به صورت خودکار شروع می‌شود.

## فایل‌های سه‌بعدی و HDRI

به دلیل حجم بالا و همچنین تفاوت در مجوز استفاده از Assetها، فایل‌های اصلی سه‌بعدی و HDRI داخل Repository قرار نگرفته‌اند.

فرمت‌هایی مانند موارد زیر توسط `.gitignore` نادیده گرفته می‌شوند:

```text
*.glb
*.exr
*.hdr
```

کاربر می‌تواند مدل‌ها و محیط‌های موردنظر خودش را به پروژه اضافه کند.

در نتیجه این پروژه فقط به جت جنگنده محدود نیست و می‌تواند برای دسته‌های مختلف استفاده شود.

برای مثال:

- هواپیما
- خودرو
- پهپاد
- ربات
- قطعات صنعتی
- ماشین‌آلات
- محصولات تجاری

## چرا Synthetic Data؟

ساخت دیتاست واقعی معمولاً نیازمند زمان و هزینه زیادی است.

برای مثال:

- جمع‌آوری تصاویر واقعی
- تصویربرداری در شرایط مختلف
- لیبل‌گذاری دستی

با استفاده از Synthetic Data می‌توان بخش بزرگی از این فرایند را خودکار کرد.

Blender امکان کنترل دقیق موارد زیر را فراهم می‌کند:

- وضعیت سوژه
- وضعیت دوربین

- اندازه سوژه
- محل قرارگیری سوژه در تصویر
- تعداد تصاویر
- لیبل‌ها

این موضوع باعث می‌شود Synthetic Data ابزار مناسبی برای آزمایش، توسعه و آموزش سیستم‌های بینایی ماشین باشد.

## محدودیت فعلی

در نسخه فعلی، HDRI به عنوان پس‌زمینه و منبع نور استفاده می‌شود.

HDRI یک محیط سه‌بعدی واقعی نیست.

در نتیجه، برای مثال جت نمی‌تواند واقعاً پشت یک درخت یا ساختمان داخل HDRI قرار بگیرد.

در نسخه‌های آینده می‌توان محیط‌های سه‌بعدی واقعی را اضافه کرد تا Occlusion و تعامل هندسی با محیط نیز امکان‌پذیر شود.
